# ガントチャート Web表示 ＆ Googleスライド出力（Google Apps Script）

バージョン：1.4.0（2026-10-22）

Googleスプレッドシートに入力したタスクから、週単位のガントチャートを作ります。
画面でその場で確認でき、顧客向けのGoogleスライドにも出力できます。

---

## できること

- **ガントチャートの表示**
  - 分類ごとにまとめて表示し、色分けと分類全体の期間線を付けます。
  - ガントはバー、マイルストーンは◆で表示します。
  - 後続の作業IDがある作業どうしを、カギ線の矢印でつなぎます。
- **進捗と担当**：バーを進捗率に応じて塗り分け、担当を列に表示します。進捗列は設定で非表示にできます。
- **本日線**：基準日の位置に赤い線を引きます。基準日が空なら線は引きません。
- **期間行**：最上段にスプリントなどの期間を表示します。スプリント以外の期間も入れられ、重なる期間は段を分けて表示します。
- **画面での確認**：スプレッドシートのダイアログ、Webアプリ、別タブで表示できます。
  - 見出しと左の表（ID〜進捗）を固定したまま、縦横にスクロールできます。
  - 文字サイズを4段階（小／標準／大／特大）で切り替えられます。
- **Googleスライド出力**
  - ガントチャート本体は高解像度の画像で貼り付けます。
  - タイトル・基準日・機密表示・会社名はスライドのテキストなので、スライド上で直接直せます。
  - 作業が多いときは、分類の途中で切らないように複数枚に分けます。
  - 作業明細はスピーカーノートに出力します。

---

## ファイル構成

| ファイル | 内容 |
|---|---|
| `Code.gs` | サーバー側。シートの読み込み、メニュー、スライドの作成、入力シートの作成 |
| `index.html` | 画面とガントチャートの描画（Web表示とスライド用の画像を同じ処理で作る） |
| `appsscript.json` | プロジェクト設定（タイムゾーン、Webアプリの公開設定） |

## 導入方法

### A. 共有されたスプレッドシートをコピーする（かんたん）

1. 受け取ったリンク（末尾が `/copy`）を開き、「コピーを作成」を押します。スクリプトもシートと一緒にコピーされます。
2. コピーしたスプレッドシートを開き直すと、メニューに「ガントチャート」が出ます。
3. 「ガントチャート ＞ 表示・スライド出力」を選びます。
4. 初回だけ権限の確認画面が出るので、許可します（「トラブルシューティング」の項目を参照）。

### B. ファイルから手動で設定する

1. Googleスプレッドシートを新しく作ります。
2. 「拡張機能 ＞ Apps Script」を開きます。
3. エディタに `Code.gs` を作り、中身を貼り付けます。
4. 「＋ ＞ HTML」で `index` という名前のファイルを作り、`index.html` の中身を貼り付けます。名前は拡張子なしで「index」にしてください。
5. 「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」をオンにし、`appsscript.json` の中身を貼り付けます。
6. 保存してスプレッドシートを再読み込みし、メニュー「ガントチャート ＞ 入力シートを作成」を実行します。
   - **サンプル付き**：サンプルデータ入りのシートを作ります。動作確認向けです。
   - **空**：見出しだけのシートを作ります。

### Webアプリとして公開する（任意）

スプレッドシートを開かずに、ブラウザのURLで見られるようにする場合の手順です。

1. Apps Scriptで「デプロイ ＞ 新しいデプロイ ＞ 種類：ウェブアプリ」を選びます。
2. 「次のユーザーとして実行」は「自分」にします。
3. 「アクセスできるユーザー」を選びます。初期値は「自分のみ」です。社内で共有する場合は組織内などに変更してください。
4. デプロイすると表示されるURL（末尾が `/exec`）を開きます。

コードを更新したときは、「デプロイを管理」で編集アイコンを押し、バージョンを「新バージョン」にして更新します。新しくデプロイし直すとURLが変わるので注意してください。

## 入力シート

### 「タスク」シート

| 列 | 必須 | 内容 |
|---|---|---|
| 分類 | ○ | グループ名。同じ分類は1つにまとめ、色分けします |
| 作業ID | ○ | 一意のID（例：A-01） |
| 作業名 | ○ | |
| 区分 | ○ | `ガント` または `マイルストーン` |
| 開始日 | ○ | マイルストーンは空でも可 |
| 終了日 | | マイルストーンはこの日付に◆を置きます（空なら開始日） |
| 作業明細 | | スライドのスピーカーノートに出力します |
| 後続の作業ID | | 依存先のID。複数あればカンマ区切り（例：`B-02, B-03`） |
| 担当 | | 例：当社／お客様／共同、または個人名 |
| 進捗率 | | 0〜100。「60%」表示のセルでも可 |

### 「スプリント」シート（任意）

| 列 | 内容 |
|---|---|
| 名称 | 例：Sprint 1、年末年始休業 |
| 表示名 | 枠が狭いときに出す短い名前。自由入力で、空なら名称から自動で作ります（例：S1） |
| 開始日／終了日 | 片方だけでも可（1日の期間として表示） |
| メモ | 1枚目のスライドのスピーカーノートに出力します |

- シートがない、または表示範囲に期間が1件もない場合は、期間行を表示しません。
- 以前の形式の見出し（スプリント名／ゴール）のままでも読み込めます。

### 「設定」シート

A列に項目名、B列に値を入れます。行の順番は自由です。

| 項目 | 内容 | 空欄のとき |
|---|---|---|
| プロジェクト名 | タイトルに表示 | ファイル名 |
| 基準日 | 本日線を引く日付 | 本日線を引かない |
| 会社名 | スライドの右下に表示 | 表示しない |
| 機密表示 | スライドの左下に赤字で表示 | 表示しない |
| 期間行の見出し | 期間行の左に表示する見出し（例：スプリント、フェーズ） | スプリント |
| 進捗を表示 | `する`／`しない`。しないにすると進捗列を消し、バーをすべて塗りつぶします | する |
| 1ページ行数 | スライド1枚の最大行数（分類見出しを含む、5〜18） | 14 |
| 出力フォルダID | スライドを保存するGoogleドライブのフォルダID | スプレッドシートと同じフォルダ |

## 使い方

1. メニュー「ガントチャート ＞ 表示・スライド出力」を開きます。
2. 画面上部のボタンで操作します。
   - **全体表示／スライドプレビュー**：全件を縦に並べた表示と、スライドの1枚ごとの表示を切り替えます。
   - **文字（小〜特大）**：画面の文字サイズを切り替えます。
   - **再読み込み**：シートの最新内容を読み込み直します。
   - **別タブで開く**：表示中のガントチャートを新しいタブに表示します。別タブは開いた時点の内容で、更新したいときはスプレッドシートから開き直してください。
   - **Googleスライドに出力**：新しいスライドを作り、完了するとリンクを表示します。
3. 入力ミスがある場合は、画面上部に警告を表示します（IDの重複、存在しない後続ID、日付の不備など）。

---

## 注意事項

- スライドのガントチャートは画像です。内容を直すときは、スプレッドシートを直して再出力してください。
- 週の数が多い（約30週を超える）場合は列が狭くなり、日付ラベルが隔週表示になります。
